
# EcoRoute AI - Dataset Sources

## Dataset 01: Heavy-Duty Truck Trajectories

Source: Dryad

Title: Real-world heavy-duty truck trajectories
on signalized corridors

Authors:
- Zhensong Wei
- Dylan Brown
- Peng Hao
- Kanok Boriboonsomsin

Publication year: 2022

DOI: 10.6086/D1BT3K

URL: https://doi.org/10.6086/D1BT3K

Data type: Real-world vehicle telemetry

Sampling frequency: 1 Hz

Documented measurements:
- Vehicle speed (mph)
- Fuel rate (litres/second)
- Distance to next intersection (metres)

Purpose:
- Study actual fuel consumption
- Analyse driving behaviour
- Evaluate fuel simulation assumptions
- Investigate machine learning feasibility

Limitations:
- Limited vehicle and geographic coverage
- Payload and gradient availability not verified
- Generalization to Indian roads not established

License and usage conditions:
- Pending verification

Status: Initial dataset investigation
